La PK sale editable (no gris)

El Navegador intenta detectar el AUTO_INCREMENT, pero el driver ODBC de MySQL no le entrega ese dato (lo comprobamos en tu máquina con tblempleado). Por eso idProducto [PK] aparece como un campo blanco normal con la etiqueta en rojo. Déjalo vacío y MySQL lo numera solo; si escribes un número que ya existe sale "Ya existe un registro con el mismo valor en un campo único." El manual de usuario hace lo mismo: escribe idEmpleado = 4 a mano.

Por qué la FK tiene que ser real

El combo de categorías sale porque el Navegador encuentra la llave foránea declarada con CONSTRAINT … FOREIGN KEY … REFERENCES. Si solo pones una columna idCategoria INT sin la CONSTRAINT, el Navegador la trata como un número cualquiera y verás un TextBox en vez del combo.

Antes del paso 2: ¿qué es el IdModulo? (y por qué «Inventario»)

⏱ 3 min de lectura · 📍 Concepto clave de Seguridad, léelo aunque tengas prisa

En una frase

El IdModulo no es un inventario de nada y no crea nada: es solo el número de una fila de la tabla tblmodulo. Un módulo es un área de la empresa (Producción, Inventario, Ventas, Seguridad) que agrupa pantallas. Seguridad usa ese número como parte de la «dirección» de los permisos: rol + módulo + aplicación.

La jerarquía de Seguridad

El sistema de Embutidos de Calidad S.A. se organiza como un edificio: el módulo es el piso (un área de la empresa), la aplicación es una oficina de ese piso (una pantalla, por ejemplo «Productos») y el permiso es la llave que tiene cada rol para esa oficina (qué botones puede usar).

Los módulos que existen en tu base

Estos son los 5 registros reales de tblmodulo en dbsistemaembutidos. La descripción es la que está guardada en la base.

¿Por qué «Inventario» para productos?

La empresa fabrica y vende embutidos. El catálogo de lo que produce (chorizo parrillero, jamón de pavo, salchicha Viena…) con sus categorías es producto terminado, que es literalmente la descripción del módulo 2. Por eso la pantalla «Productos» se registra dentro de Inventario.

No hay una única respuesta correcta

También se podría defender poner productos en Ventas. Lo que se evalúa es que sepas explicar la elección y que el número sea el mismo en los tres lugares. Si el catedrático dice «ponlo en Ventas», cambia el 2 por 3 en los tres.

using System;
using System.Drawing;

namespace PruebaExamen
{
    public partial class FrmLogin : Form
    {
        private readonly TextBox TxtUsuario = new TextBox();
        private readonly TextBox TxtContrasena = new TextBox();
        private readonly Button BtnIngresar = new Button();

        public FrmLogin()
        {
            InitializeComponent();

            Text = "Iniciar sesión";
            StartPosition = FormStartPosition.CenterScreen;
            FormBorderStyle = FormBorderStyle.FixedDialog;
            MaximizeBox = false;
            MinimizeBox = false;
            ClientSize = new Size(320, 170);

            Controls.Add(new Label { Text = "Usuario", Location = new Point(20, 20), AutoSize = true });
            TxtUsuario.SetBounds(120, 17, 180, 23);
            Controls.Add(TxtUsuario);

            Controls.Add(new Label { Text = "Contraseña", Location = new Point(20, 60), AutoSize = true });
            TxtContrasena.SetBounds(120, 57, 180, 23);
            TxtContrasena.UseSystemPasswordChar = true;
            Controls.Add(TxtContrasena);

            BtnIngresar.Text = "Ingresar";
            BtnIngresar.SetBounds(120, 105, 180, 35);
            BtnIngresar.Click += BtnIngresar_Click;
            Controls.Add(BtnIngresar);
            AcceptButton = BtnIngresar;
        }

        private void BtnIngresar_Click(object sender, EventArgs e)
        {
            try
            {
                // Valida contra tblusuario (BCrypt) y deja la sesión de Seguridad iniciada
                if (new ClsModeloUsuario().SeguridadMetIniciarSesion(TxtUsuario.Text.Trim(), TxtContrasena.Text))
                {
                    DialogResult = DialogResult.OK;   // cierra el login; Program abre Form1
                }
                else
                {
                    MessageBox.Show("Usuario o contraseña incorrectos.", "Acceso denegado",
                        MessageBoxButtons.OK, MessageBoxIcon.Warning);
                    TxtContrasena.Clear();
                    TxtContrasena.Focus();
                }
            }
            catch (Exception Excepcion)
            {
                MessageBox.Show("No se pudo conectar con Seguridad (revise el DSN EmbutidosS.A).\n\n" + Excepcion.Message,
                    "Error de conexión", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
        }
    }
}
