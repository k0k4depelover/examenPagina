Capa Vista: el botón y la ventana del reporte

⏱ 10 min · 📍 CapaVista_Reporteador

La Vista tiene 2 archivos. Los dos se crean solo con código: no arrastras nada en ningún diseñador.

BtnReporteador.cs

El control (un botón «Reporte») que luego arrastras a Form1, igual que hiciste con el Navegador. Se configura en una línea.

FrmVisorReporte.cs

La ventana que se abre al hacer clic. Dentro tiene un ReportViewer (el visor del NuGet) que dibuja el .rdlc con los datos.

1. Crear el botón: BtnReporteador

  1. En el Explorador de soluciones: clic derecho en CapaVista_Reporteador › Agregar › Control de usuario (Windows Forms)…
  2. Nombre: BtnReporteador.cs › Agregar. Se abre un cuadro gris vacío (el diseñador). No arrastres nada ahí: el botón se crea por código.
  3. Pulsa F7 (Ver código). Se abre BtnReporteador.cs.
  4. Selecciona todo (Ctrl+A), bórralo y pega el código de abajo. Guarda con Ctrl+S.
  5. No borres BtnReporteador.Designer.cs (el archivo que cuelga debajo): ahí vive InitializeComponent(), que el código llama.
C# · CapaVista_Reporteador/BtnReporteador.cs
using System;
using System.Data;
using System.Drawing;
using System.Windows.Forms;
using CapaControlador_Reporteador;

namespace CapaVista_Reporteador
{
    // Control del Reporteador: un botón que se arrastra a cualquier formulario
    // y se configura en una línea (igual que el Navegador).
    public partial class BtnReporteador : UserControl
    {
        private readonly Button _Boton = new Button();
        private readonly ClsControladorReporte _Controlador = new ClsControladorReporte();
        private string _Tabla;
        private string _Consulta;
        private string _RutaReporte;
        private int _NumeroReporte;
        private string _NombreDataSet = "DsReporte";

        public BtnReporteador()
        {
            InitializeComponent();

            _Boton.Text = "Reporte";
            _Boton.Dock = DockStyle.Fill;
            _Boton.FlatStyle = FlatStyle.Flat;
            _Boton.BackColor = Color.FromArgb(91, 15, 21);
            _Boton.ForeColor = Color.White;
            _Boton.Font = new Font("Segoe UI", 10F, FontStyle.Bold);
            _Boton.Click += (Remitente, Evento) => ReporteadorMetMostrar();
            Controls.Add(_Boton);
            Size = new Size(120, 45);
        }

        // Tabla + ruta del .rdlc (si la ruta va vacía, el botón pide elegir el archivo)
        public void ReporteadorMetConfigurar(string Tabla, string RutaReporte, string NombreDataSet = "DsReporte")
        {
            _Tabla = Tabla;
            _Consulta = null;
            _RutaReporte = RutaReporte;
            _NumeroReporte = 0;
            _NombreDataSet = NombreDataSet;
        }

        // Un SELECT propio (por ejemplo con JOIN) + ruta del .rdlc
        public void ReporteadorMetConfigurarConsulta(string ConsultaSelect, string RutaReporte, string NombreDataSet = "DsReporte")
        {
            _Tabla = null;
            _Consulta = ConsultaSelect;
            _RutaReporte = RutaReporte;
            _NumeroReporte = 0;
            _NombreDataSet = NombreDataSet;
        }

        // Tabla + número de reporte registrado en tblreporte (la ruta sale de la BD)
        public void ReporteadorMetConfigurarDesdeBD(string Tabla, int NumeroReporte, string NombreDataSet = "DsReporte")
        {
            _Tabla = Tabla;
            _Consulta = null;
            _RutaReporte = null;
            _NumeroReporte = NumeroReporte;
            _NombreDataSet = NombreDataSet;
        }

        // Carga y muestra el reporte (lo usa el clic y también se puede llamar desde el formulario)
        public void ReporteadorMetMostrar()
        {
            try
            {
                string Ruta;
                if (_NumeroReporte > 0)
                    Ruta = _Controlador.ReporteadorFuncRutaDesdeBD(_NumeroReporte);
                else if (!string.IsNullOrWhiteSpace(_RutaReporte))
                    Ruta = _Controlador.ReporteadorFuncRutaValida(_RutaReporte);
                else
                {
                    string Elegida = ReporteadorFuncElegirArchivo();
                    if (Elegida == null) return;   // canceló
                    Ruta = _Controlador.ReporteadorFuncRutaValida(Elegida);
                }

                DataTable Datos = _Consulta != null
                    ? _Controlador.ReporteadorFuncDatosConsulta(_Consulta)
                    : _Controlador.ReporteadorFuncDatosTabla(_Tabla);

                using (FrmVisorReporte Visor = new FrmVisorReporte(
                    "Reporte - " + (_Tabla ?? "consulta"), Ruta, _NombreDataSet, Datos))
                {
                    Visor.ShowDialog(FindForm());
                }
            }
            catch (Exception Excepcion)
            {
                MessageBox.Show("No se pudo cargar el reporte.\n\n" + Excepcion.Message,
                    "Reporteador", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
        }

        private string ReporteadorFuncElegirArchivo()
        {
            using (OpenFileDialog Dialogo = new OpenFileDialog())
            {
                Dialogo.Title = "Seleccione un reporte";
                Dialogo.Filter = "Reportes RDLC (*.rdlc)|*.rdlc";
                return Dialogo.ShowDialog() == DialogResult.OK ? Dialogo.FileName : null;
            }
        }
    }
}

2. Crear la ventana: FrmVisorReporte

  1. Clic derecho en CapaVista_Reporteador › Agregar › Clase…
  2. Nombre: FrmVisorReporte.cs › Agregar.
  3. Borra todo lo que trae (Ctrl+A, Supr) y pega el código de abajo. Guarda.
  4. Es una clase que hereda de Form: el ReportViewer se crea por código, no hace falta ponerlo desde el Cuadro de herramientas. Si luego le das doble clic y se abre un diseñador vacío, ciérralo; para ver el código usa clic derecho › Ver código (F7).
C# · CapaVista_Reporteador/FrmVisorReporte.cs
using System.Data;
using System.Windows.Forms;
using Microsoft.Reporting.WinForms;

namespace CapaVista_Reporteador
{
    // Ventana que muestra el .rdlc con los datos (ReportViewer creado por código)
    public class FrmVisorReporte : Form
    {
        private readonly ReportViewer _Visor = new ReportViewer();

        public FrmVisorReporte(string Titulo, string RutaRdlc, string NombreDataSet, DataTable Datos)
        {
            Text = Titulo;
            Width = 1000;
            Height = 700;
            StartPosition = FormStartPosition.CenterParent;

            _Visor.Dock = DockStyle.Fill;
            _Visor.ProcessingMode = ProcessingMode.Local;
            _Visor.LocalReport.ReportPath = RutaRdlc;
            _Visor.LocalReport.DataSources.Clear();
            _Visor.LocalReport.DataSources.Add(new ReportDataSource(NombreDataSet, Datos));
            Controls.Add(_Visor);

            Load += (Remitente, Evento) => _Visor.RefreshReport();
        }
    }
}

Qué pasa cuando haces clic

«DsReporte» tiene que ser IDÉNTICO en los dos lados

El nombre que el código le da a los datos ("DsReporte", en new ReportDataSource(NombreDataSet, Datos)) debe ser exactamente el mismo que el del .rdlc: <DataSet Name="DsReporte"> (mayúsculas incluidas). Si no coinciden sale: A data source instance has not been supplied for the data source 'X'.

El reporte .rdlc (el diseño de la hoja)

⏱ 8 min · 📍 PruebaExamen › carpeta Reportes

Un .rdlc es un archivo XML que describe cómo se ve la hoja: qué campos recibe (el DataSet), la tabla del cuerpo (la Tablix) y el encabezado/pie. Los datos no están dentro: se los pasa el código (el DataTable del Controlador) al abrirlo.

  1. Descárgalo si no lo tienes: RpProductos.rdlc.
  2. En PruebaExamen: clic derecho › Agregar › Nueva carpeta › nómbrala Reportes.
  3. Clic derecho en Reportes › Agregar › Elemento existente…
  4. Abajo a la derecha cambia el filtro a Todos los archivos (*.*) ▾.
  5. Elige C:\Users\oskar\Desktop\examenPaginaUrgente\archivos\RpProductos.rdlc › Agregar (Visual Studio lo copia dentro de Reportes).

Opción B: pegar el XML

  1. Crea la carpeta Reportes (igual que en A).
  2. Clic derecho en Reportes › Agregar › Nuevo elemento… › busca «Archivo XML».

e) Preguntas que te pueden hacer

¿Por qué 3 capas?
Para separar responsabilidades: si cambia la base de datos solo toco el Modelo; si cambia la pantalla o el visor (RDLC → Crystal) solo toco la Vista. Cada capa se puede reutilizar y probar por separado, y el botón se reutiliza en cualquier formulario con una línea.
¿Qué hace cada capa?
Modelo (ClsConexion, ClsSentenciasReporte): habla con MySQL por ODBC, ejecuta el SELECT y devuelve un DataTable; lee la ruta de tblreporte. Controlador (ClsControladorReporte): valida (nombre de tabla con Regex, solo SELECT, que la ruta exista y sea .rdlc) y pide los datos al Modelo. Vista (BtnReporteador, FrmVisorReporte): el botón y la ventana; solo habla con el Controlador.
¿Qué es un RDLC y qué es ReportViewer?
El .rdlc (Report Definition Language Client-side) es un XML con el diseño del reporte: campos, tabla, encabezado y pie. ReportViewer es el control de Microsoft (NuGet Microsoft.ReportingServices.ReportViewerControl.Winforms) que toma ese diseño + los datos, lo dibuja y permite imprimir, exportar a PDF/Excel/Word, hacer zoom y buscar.
¿Procesamiento local o de servidor?
Local (ProcessingMode.Local): el reporte se procesa en la misma PC con los datos que le pasa el programa; no hace falta un servidor. Remoto sería con SQL Server Reporting Services (archivos .rdl publicados en un servidor), que no usamos.
¿Qué es el DataSet del .rdlc y por qué debe llamarse igual?
Es la lista de campos que el reporte espera (<DataSet Name="DsReporte"> con sus <Fields>). En código se le entrega el DataTable con new ReportDataSource("DsReporte", Datos): el ReportViewer une ambos por nombre. Si no coinciden: A data source instance has not been supplied…
¿Cómo evitas la inyección SQL?
El nombre de tabla se valida con una Regex (solo letras, números y _), las consultas propias solo se aceptan si son SELECT, y la búsqueda en tblreporte usa un parámetro ? (ODBC) en lugar de concatenar el número.
¿Para qué sirven tblreporte y tblaplicacionreporte?
tblreporte es el catálogo de reportes (número, nombre único, ruta del archivo, fecha): así la ruta no queda fija en el código y se puede cambiar desde la BD. tblaplicacionreporte liga cada reporte con la aplicación de Seguridad a la que pertenece (por ejemplo «Productos» → reporte 1).
¿Qué cambiarías para usar Crystal Reports?
Instalar SAP Crystal Reports for Visual Studio + runtime, diseñar un .rpt y en la Vista cambiar ReportViewer por CrystalReportViewer (ReportDocument.Load + SetDataSource). Modelo y Controlador quedan igual.
